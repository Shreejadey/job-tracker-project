# 📌 Job Tracker Project

A simple and effective *Job Application Tracker* built to help users manage and monitor their job applications in one place.  
This project is deployed using *GitHub Pages* and accessible online.

🔗 *Live Demo*: [Click here to view](https://shreejadey.github.io/job-tracker-project/)

---

## 🚀 Features
- ✅ Add, edit, and delete job applications  
- ✅ Track status (Applied, Interview, Offer, Rejected)  
- ✅ Responsive design for mobile and desktop  
- ✅ Simple and clean UI for better productivity  

---

## 🛠 Tech Stack
- *Frontend*: HTML, CSS, JavaScript  
- *Deployment*: GitHub Pages
